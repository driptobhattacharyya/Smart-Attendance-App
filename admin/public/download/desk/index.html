Attendify Desk for Windows

Attendify Desk turns your office computer into the desk beacon, so Attendify knows you are at your desk without a Bluetooth tag.

What you need

  • Windows 10 or 11.
  • Bluetooth. Most laptops have it built in. Many desktops need a small USB Bluetooth adapter.
  • A pairing code from your administrator, shown in the Attendify admin console.

Install and pair

  1. Download the installer and run it.
  2. Open Attendify Desk and enter the pairing code.
  3. Leave it running on that computer while you work.

What it shares

Only whether the computer is locked, how many seconds since the last key press or mouse movement, whether it is broadcasting, the app version, and the computer name and operating system. It never records keystrokes, screenshots, window titles or which apps you use.
